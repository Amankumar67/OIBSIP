# 🔐 Random Password Generator

A simple and secure **Random Password Generator** built using Python as part of my **Python Programming Internship at Oasis Infobyte**. This command-line application generates strong passwords based on user preferences such as password length and character types while validating user input.

---

## 📌 Project Overview

Strong passwords are essential for protecting online accounts and personal information. This project allows users to generate customizable passwords by selecting the desired password length and character types, ensuring a secure and user-friendly experience.

---

## 🚀 Features

- Generate random passwords
- User-defined password length (minimum 8 characters)
- Select character types:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special symbols
- Ensures at least two character types are selected
- Input validation for invalid password lengths and selections
- Option to generate multiple passwords without restarting the program
